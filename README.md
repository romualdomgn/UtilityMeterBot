# 📊 Utility Meter Bot & Web App

Комплексное решение на базе **Python (FastAPI + Aiogram 3)** для автоматизации учёта показаний коммунальных счетчиков, контроля аренды недвижимости, расчёта коммунальных платежей и напоминаний жильцам и собственникам через Telegram Web App.

---

## ✨ Ключевые возможности

### 🏠 Управление недвижимостью и мультиаренда (Multi-Tenancy)
- **Изолированное разделение прав:** Поддержка нескольких семей/групп пользователей. Каждая семья имеет собственный доступ к объектам недвижимости.
- **Роли пользователей:**
  - **Суперадминистратор (`ADMIN_TELEGRAM_ID`):** Полный доступ к управлению системой и ротацией прав.
  - **Владелец квартиры:** Полные права на добавление счетчиков, тарифов, жильцов и генерацию отчетов.
  - **Наниматель (Жилец):** Ограниченный доступ к подаче показаний по привязанной квартире. При выезде жилец открепляется от конкретного объекта без удаления аккаунта.

### 📈 Учёт показаний и Тарифы
- **Календарный расчёт (Billing Calendar):** Автоматический расчет стоимости по расчётным периодам (календарный месяц).
- **Исторические тарифы:** Тарифные ставки фиксируются на момент подачи показаний, что обеспечивает точные вычисления даже при смене тарифов ЖКХ.
- **Защита от нулевой базы:** Требуется первичная (базовая) фиксация показаний до начала начисления стоимости.
- **Умная обработка дат подачи:** Автоматический перенос крайних дат подачи (29, 30, 31 числа) в коротких месяцах (например, феврале).

### 🤖 Telegram Web App & Бот
- **Интерактивный WebApp:** Удобный интерфейс внутри Telegram для ввода показаний, просмотра истории и счетов.
- **Безопасная аутентификация:** Проверка `initData` от Telegram на бэкенде с валидацией хэша HMAC-SHA256 (`/api/me`).
- **Защита от XSS / HTML Injection:** Автоматическое HTML-экранирование всех пользовательских вводных данных в уведомлениях и боте.

### ⏰ Фоновые задачи (APScheduler)
1. `check_meter_reminders` — Уведомления и напоминания о необходимости сдать показания.
2. `check_lease_expirations` — Напоминания о завершении срока аренды.
3. `create_backup` — Автоматическое резервное копирование базы данных SQLite.
4. `cleanup_old_photos` — Автоматическая очистка фотофиксаций счетчиков старше 30 дней для экономии места на сервере.

## 🛠 Технологический стек

- **Язык программирования:** Python 3.12
- **Веб-фреймворк:** FastAPI / Uvicorn
- **Telegram Bot Framework:** Aiogram 3.x
- **ORM / База данных:** SQLAlchemy 2.0 / SQLite 3
- **Планировщик задач:** APScheduler
- **Контейнеризация:** Docker / Docker Compose
- **Тестирование:** Pytest / Pytest-Asyncio

## 🚀 Быстрый запуск и развёртывание

### 1. Требования
- Установленный `docker` и `docker-compose`
- Telegram Bot Token (полученный у `@BotFather`)

### 2. Переменные окружения (`.env`)
Создайте файл `.env` в корневом каталоге проекта:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyZ
ADMIN_TELEGRAM_ID=9234604265
WEBAPP_URL=https://utility-meter.litvinov.uk
DATABASE_URL=sqlite+aiosqlite:///data/utility_meter.db
```

### 3. Запуск через Docker Compose

```bash
# Клонирование и переход в каталог проекта
cd /opt/utility_meter_bot

# Сборка и запуск контейнеров в фоновом режиме
sudo docker compose up -d --build
```

Проверить статус контейнеров и логи:
```bash
sudo docker compose ps
sudo docker compose logs -f utility-meter-app
```

## 🧪 Тестирование и проверка качества

Тесты покрывают критическую бизнес-логику безопасности, расчётов тарифов, изоляции пользователей и ротации админов.

### Запуск тестов внутри контейнера

```bash
sudo docker compose exec -T utility-meter-app pytest -v
```

### Набор регрессионных тестов (`pytest`):
* `test_critical_01_cross_family_owner_delete_blocked` — Проверка запрета удаления владельцев из чужих семей.
* `test_critical_02_admin_rotation_revokes_old_admin` — Автоматический отзыв прав при смене `ADMIN_TELEGRAM_ID`.
* `test_critical_03_and_medium_04_remove_tenant_isolation` — Изоляция открепления жильца без удаления аккаунта.
* `test_high_01_02_05_billing_calendar_historical_tariff_and_no_base` — Корректность начислений, календарный расчёт и защита от нулевой базы.
* `test_medium_01_delete_family_revokes_users` — Каскадный отзыв доступа при удалении семьи.
* `test_medium_03_effective_submission_day` — Корректировка дней подачи в коротких месяцах.
* `test_high_09_photo_retention_cleanup` — Проверка автоматического удаления фото старше 30 дней.
* `test_medium_05_html_escaping_in_notifications` — Проверка экранирования спецсимволов HTML во избежание инъекций.

## 🔒 Безопасность

1. **Telegram InitData Validation:** Все эндпоинты `/api/*` проверяют подпись Telegram HMAC-SHA256. Вход без валидного токена возвращает `401 Unauthorized`.
2. **HTML Sanitization:** Данные, вводимые пользователями (названия квартир, комментарии), экранируются перед отправкой в сообщениях Telegram.
3. **Безопасное хранение фото:** Загруженные снимки показаний хранятся со случайными UUID-именами и автоматически очищаются по истечении 30 суток.
