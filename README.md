# 📊 Utility Meter Bot & Web App

Комплексное решение на базе **Python 3.12 (FastAPI + Aiogram 3 + SQLAlchemy 2.0)** для учёта показаний счётчиков воды, электричества и газа по разным объектам недвижимости, контроля аренды, расчёта начислений и автоматических напоминаний через Telegram Mini App.

---

## ✨ Ключевые возможности

### 🏘 Управление недвижимостью и счётчиками
- **Типы недвижимости:** поддержка объектов типов **Квартира** (`🏢`), **Дом** (`🏡`) и **Дача** (`🌿`).
- **Гибкий набор счётчиков на каждый объект:** при создании и в настройках объекта выбираются только реально установленные счётчики из набора:
  - 💧 **ХВС** (м³) и ♨️ **ГВС** (м³);
  - ⚡ **Электричество** — Т1, Т2, Т3 (кВт·ч);
  - 🔥 **Газовый счётчик** (м³).
- **Частичная подача показаний:** на вкладке «Подать» отображаются только подключённые для объекта группы ресурсов и счётчики; допускается подача по отдельным счётчикам.
- **Безопасная миграция SQLite:** при запуске `init_db()` автоматически добавляет недостающие столбцы (`property_type`, `enabled_meters`, `gas_submission_day`) в таблицу `apartments` через `ALTER TABLE ... ADD COLUMN` без потери данных. Для существующих объектов автоматически сохраняется совместимость с прежним набором из 5 счётчиков.

### 👨‍👩‍👧‍👦 Семьи, роли и профили
- **Изолированные семьи:** каждая семья видит и управляет только своими объектами недвижимости.
- **Роли пользователей:**
  - **Администратор (`ADMIN_TELEGRAM_ID`):** полный доступ, управление семьями, журнал аудита, бэкапы и выгрузки в разделе **«Управление»**.
  - **Владелец (`landlord`):** управление недвижимостью своей семьи, договорами, жильцами, тарифами, редактирование имён и телефонов членов семьи, выгрузка отчётов в Excel/PDF.
  - **Наниматель (`tenant`):** подача показаний, просмотр истории и отправка фото по привязанным объектам. Одного нанимателя можно привязать к нескольким объектам своей семьи.
- **Самостоятельная смена имени:** любой авторизованный пользователь (владелец, наниматель, администратор) может изменить своё отображаемое имя по клику на имя в шапке Mini App (`PUT /api/me/profile`).
- **Редактирование членов семьи:** в разделе **«Семья»** доступно изменение имени и телефона каждого владельца (`PUT /api/families/{family_id}/owners/{owner_tg_id}`).

### 📈 Расчёты, тарифы и отчёты
- **Календарный расчёт:** автоматический расчёт расхода и стоимости за месяц по воде, электричеству и газу с учётом исторических тарифов на дату периода.
- **Защита истории тарифов от дублей:** при сохранении настроек новые записи в таблицу `tariffs` добавляются только для фактически изменённых ставок.
- **Защита от нулевой базы:** без заданного начального показания стоимость не начисляется.
- **Выгрузка в чат (Excel / PDF):** перенесена из «Обзора» в раздел **«Управление»** (для администратора) и в раздел **«Недвижимость»** (для владельца). Поддерживается выгрузка как по выбранному объекту, так и по всем доступным объектам.

### 🤖 Telegram Mini App & UX
- **Безопасная аутентификация:** проверка `initData` по HMAC-SHA256 с оптимизированным разрешением прав (`resolve_user_access`).
- **Маска телефона `+7-xxx-xxx-xxxx`:** в формах добавления и редактирования владельцев/нанимателей поле телефона сразу подставляет `+7-` и автоматически форматирует ввод.
- **Кликабельная подсказка `@userinfobot`:** в окнах добавления владельца и нанимателя ссылка на `@userinfobot` открывается напрямую в Telegram.
- **Отзывчивый интерфейс:** спиннер загрузки при переключении вкладок и объектов, виброотклик `HapticFeedback`, цветные toast-уведомления с закрытием по тапу и валидация модальных окон без потери введённых данных.

### ⏰ Фоновые задачи (APScheduler)
1. `check_meter_reminders` — напоминания о подаче показаний воды, электричества и газа только по подключённым на объекте счётчикам (с переносом 29–31 чисел в коротких месяцах).
2. `check_lease_expirations` — уведомления за 7 дней и в день окончания договора найма.
3. `create_backup` — ежедневный инкрементальный бэкап SQLite (`pages=100, sleep=0.01`, хранение последних 14 копий).
4. `cleanup_old_photos` — автоматическая очистка фото счётчиков старше 30 дней.

## 🛠 Технологический стек

- **Язык:** Python 3.12
- **Веб-сервер и API:** FastAPI / Uvicorn
- **Telegram-бот:** Aiogram 3.x
- **БД и ORM:** SQLite (WAL) / SQLAlchemy 2.0 (asyncio) + `aiosqlite`
- **Фоновые задачи:** APScheduler
- **Экспорт:** `openpyxl` (Excel), `fpdf2` (PDF)
- **Фронтенд:** HTML5, CSS3, Vanilla JS (Telegram WebApp SDK)
- **Тесты:** `pytest`, `pytest-asyncio`
- **Контейнеризация:** Docker / Docker Compose + Cloudflare Tunnel (`cloudflared`)

## 🚀 Запуск и обновление через Docker Compose

### 1. Переменные окружения (`.env`)
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyZ
ADMIN_TELEGRAM_ID=123456789
CLOUDFLARE_TUNNEL_TOKEN=eyJ...
WEBAPP_URL=https://utility-meter.litvinov.uk
TIMEZONE_OFFSET=5
```

### 2. Пересборка и перезапуск после обновления файлов
Так как исходный код копируется внутрь Docker-образа (`COPY . .`), после распаковки обновлённых файлов выполните пересборку и перезапуск:

```bash
cd /opt/tg_web_app
docker compose up -d --build
```

Проверка статуса и логов:
```bash
docker compose ps
docker compose logs -f utility-meter-app
```

## 🔒 Безопасность

1. **Telegram `initData` HMAC-SHA256:** все эндпоинты `/api/*` проверяют цифровую подпись и срок действия данных Telegram.
2. **Изоляция семей и белый список полей:** пользователи имеют доступ только к объектам своей семьи/договора; обновление полей объектов ограничено белым списком `ALLOWED_APARTMENT_FIELDS`.
3. **HTML-экранирование:** все пользовательские строки экранируются перед отправкой в Telegram и рендерингом в Mini App.
