# 📊 Utility Meter Bot & Web App

Комплексное решение на базе **Python 3.12 (FastAPI + Aiogram 3 + SQLAlchemy 2.0)** для учёта показаний счётчиков воды, электричества и газа по разным объектам недвижимости, контроля аренды, поверки и замены приборов учёта, расчёта начислений и автоматических напоминаний через Telegram Mini App.

---

## ✨ Ключевые возможности

### 🌆 Управление недвижимостью и счётчиками
- **Типы недвижимости:** поддержка объектов типов **Квартира** (`🏢`), **Дом** (`🏡`) и **Дача** (`🌿`).
- **Сортировка объектов перетаскиванием (Drag & Drop):** в разделе **«Недвижимость»** объекты можно перетаскивать (подсказка *«Зажмите и перетащите объект или нажмите ⇅»*), а в режиме сортировки `⇅` доступны кнопки сдвига `◀ Влево` / `Вправо ▶`; порядок сохраняется в БД (`PUT /api/apartments/reorder`).
- **Индикация просроченных показаний:** на вкладке **«Обзор»** в чипе объекта отображается компактный индикатор `🟡`, если хотя бы один подключённый счётчик не сдан после наступления установленного дня подачи.
- **Гибкий набор счётчиков на каждый объект:**
  - 💧 **ХВС** (м³), ♨️ **ГВС** (м³) и 🚰 **Водоотведение** (`ХВС + ГВС`, а при поливе после ХВС — `ХВС + ГВС минус Полив` / `ХВС минус Полив`);
  - 🌱 **Полив** (м³) — для типа **«Дом»** со схемой подключения `after_cold` (требует включённого ХВС, без двойного начисления) или `parallel` (отдельный тариф);
  - ⚡ **Электричество** — режим **«Один тариф»** (`Т`, кВт·ч) или **«Тарифы Т1, Т2, Т3»** (кВт·ч) с взаимоисключением на клиенте и сервере;
  - 🔥 **Газовый счётчик** (м³).
- **Компактный экран настроек объекта (`🌆 Недвижимость → Настройки`):** параметры разнесены по отдельным модальным окнам с быстрыми кнопками:
  - **«🏠 Настройки объекта недвижимости»** — выбор типа недвижимости (Квартира / Дом / Дача) и ввод адреса или номера объекта;
  - **«🚰 Имеющиеся счётчики воды и газа в квартире / в доме / на даче»** (подставляется по типу объекта) — выбор подключённых счётчиков, схемы полива и типа тарификации электричества;
  - **«🔧 Управление счётчиками»** — заводские номера (опционально), срок поверки и мультивыбор уведомлений (**«Полгода»**, **«3 месяца»**, **«Месяц»**, **«Неделя»**, рассылка владельцу в **15:00**). Для многотарифного электричества Т1/Т2/Т3 объединены в единую карточку **«⚡ Электрический счётчик»**, водомеры подписаны как **«💧 Водомер холодной воды»** и **«♨️ Водомер горячей воды»**. Внутри доступна кнопка **«🔄 Замена счётчика»** (поддерживается в том числе замена многотарифного электросчётчика с сохранением остатков по всем тарифам);
  - **«📅 Дни подачи показаний»** — дни напоминаний по активным группам счётчиков;
  - **«💰 Тарифы»** — действующие ставки и история изменений тарифов.
- **Контроль повторной подачи и снижения показаний:**
  - Повторная подача в том же календарном месяце (при увеличении значения) запрашивает подтверждение пользователя;
  - Ввод значения меньше ранее зафиксированного: для нанимателя строго блокируется; для владельца и администратора выводится предупреждение с двумя вариантами — прямая ссылка в **«🔧 Управление счётчиками → Замена счётчика»** (при замене прибора) либо кнопка **«Сохранить»** для подтверждения корректировки ошибочно введённого значения (с пометкой `(корректировка)` в журнале аудита и уведомлениях);
  - В форме подачи отдельно отображаются расход с последней подачи и итоговый расход за текущий месяц; защищено идемпотентностью `submission_id` от сетевых дублей.
- **Безопасная миграция SQLite:** при запуске `init_db()` автоматически создаёт новые таблицы (`family_owners`, `meter_devices`, `meter_replacements`, `meter_submissions`, `scheduler_runs`) и добавляет недостающие колонки (`apartments.*`, `meter_readings.is_replacement_init`) без потери данных.

### 👨‍👩‍👧‍👦 Люди, роли, аренда и уведомления
- **Раздел «Люди»:** объединяет управление семьями/владельцами и блок **«Наниматели»** (появляется, если у владельца есть хотя бы один наниматель): список всех нанимателей с квартирой, сроком действия договора, кнопками редактирования (`PUT /api/tenants/{tg_id}`), удаления и кнопкой **«👤 + Наниматель»**.
- **Адресная маршрутизация уведомлений и роль администратора:**
  - Все уведомления (новые показания, фото, напоминания о подаче, окончании договора и поверке счётчиков) отправляются **только владельцам (`landlord`) конкретной квартиры/семьи**, а не глобально администратору;
  - `ADMIN_TELEGRAM_ID` можно добавить как владельца в любую нужную семью через «Люди → + Владелец» (и при необходимости открепить без потери прав администратора).
- **Обзор и права нанимателя:** на вкладке **«Обзор»** наниматель видит стоимость потреблённых ресурсов в рублях в том же виде, что и владелец; при этом служебные тарифы (`tariffs`) и история тарифов (`GET /api/apartments/{id}/tariffs/history`, HTTP 403) остаются закрыты для роли `tenant`.
- **Управление договорами найма:**
  - Чип статуса на вкладке «Обзор» — **«👤 Аренда»**;
  - В разделе **«Недвижимость → Аренда»** форма раскрывается поэтапно: чек-бокс **«Объект сдаётся в аренду»** (при снятом состоянии окно остаётся пустым), при его включении появляются чек-боксы **«Наниматель проживает»** и **«Договор найма»**, открывающие соответствующие поля для заполнения;
  - Наниматель имеет доступ вне зависимости от даты начала договора (блокируется только после окончания срока);
  - Единый формат отображения и ввода дат во всём приложении — `ДД.ММ.ГГГГ` (`DD.MM.YYYY`, например `25.11.2026`);
  - Умная активация кнопок сохранения во всех формах и модальных окнах (включая «🔧 Управление счётчиками», «🔄 Замена счётчика», «📅 Дни подачи показаний», «💰 Тарифы», «📏 Начальные показания», «📋 Аренда» и «👨‍👩‍👧‍👦 Люди»): кнопка неактивна до внесения изменений и снова деактивируется при возврате данных к исходным значениям;
  - При сохранении договора со сроком более 12 месяцев выводится предупреждение о необходимости регистрации долгосрочного найма в Росреестре и рекомендации срока до 11 месяцев;
  - При нажатии **«🗑 Удалить договор»** при наличии привязанных нанимателей предлагается выбор: *«Удалить только договор (доступ нанимателя к боту сохранится)»* либо *«Удалить договор и открепить нанимателей»*;
  - В стартовом меню Telegram-бота под кнопкой **«📱 Открыть Mini App»**, а также в разделе Mini App **«🔧 Управление»** доступна кнопка **«ℹ️ О приложении»** с кликабельными ссылками на репозиторий (`REPOSITORY`) и контакт разработчика (`TgUserName`) из `.env`, и кнопка **«📖 Как пользоваться приложением»** с интерактивными справками по основным функциям бота;
  - Блок экспорта отчётов **«📤 Выгрузка базы данных»** отображает кнопки вида **«📊 Excel Квартира №XXX»** / **«📄 PDF Квартира №XXX»** (с подстановкой типа и номера выбранного объекта) и выгрузку по всем объектам.
- **Пересылка фотографий без хранения на сервере:** фотографии счётчиков из Mini App (после потоковой проверки формата изображения) и из чата пересылаются напрямую владельцам объекта в Telegram и **не сохраняются на сервере**.

### 📈 Расчёты, отчёты, бэкапы и надёжность
- **Календарный расчёт и полнота данных:** расчёт с учётом исторических тарифов, замен счётчиков и явным признаком неполноты (`is_complete`, `incomplete_reasons`) в Mini App и отчётах Excel/PDF.
- **Неблокирующий экспорт Excel/PDF:** генерация документов полностью выполняется в отдельном потоке (`asyncio.to_thread`) без блокировки event loop.
- **Умные резервные копии SQLite:** атомарная запись через временный файл с блокировкой конкурентных запусков; хранение резервных копий **не более 60 дней (2 месяцев)**; если база данных (`.db` и `-wal`) за сутки не менялась, новый файл бэкапа не создаётся.
- **Надёжность SQLite и API:** включены `PRAGMA foreign_keys=ON`, `journal_mode=WAL`, `busy_timeout=5000`, сериализованные атомарные транзакции (`UnitOfWork(write=True)`), строгие границы целых чисел Pydantic, управляемый менеджер фоновых уведомлений (`BackgroundTaskManager`), сохранение очереди обновлений Telegram при перезапуске (`DROP_PENDING_UPDATES=false`) и догоняющий запуск пропущенных ежедневных задач при старте.

### ⏰ Фоновые задачи (APScheduler, локальное время `TIMEZONE_OFFSET`)
1. `meter_reminders` (**15:00**) — напоминания о подаче показаний по подключённым счётчикам.
2. `lease_expirations` (**15:00**) — уведомления владельцам за 7 дней и в день окончания договора найма.
3. `meter_verifications` (**15:00**) — уведомления владельцам о приближающемся сроке поверки/замены счётчиков (за полгода, 3 месяца, месяц, неделю).
4. `daily_backup` (**03:00**) — инкрементальный бэкап SQLite (только при наличии изменений БД, хранение 60 дней).

## 🛠 Технологический стек

- **Язык:** Python 3.12
- **Веб-сервер и API:** FastAPI / Uvicorn
- **Telegram-бот:** Aiogram 3.x
- **БД и ORM:** SQLite (WAL) / SQLAlchemy 2.0 (asyncio) + `aiosqlite`
- **Фоновые задачи:** APScheduler
- **Экспорт:** `openpyxl` (Excel), `fpdf2` (PDF)
- **Фронтенд:** HTML5, CSS3, Vanilla JS (Telegram WebApp SDK)
- **Тесты:** `pytest`, `pytest-asyncio`
- **Контейнеризация:** Docker / Docker Compose + Cloudflare Tunnel (`cloudflared`)

## 🚀 Обновление и запуск через Docker Compose

После распаковки архива с обновлениями в каталоге проекта пересоберите и перезапустите контейнер:

```bash
cd /opt/utility_meter_bot
docker compose up -d --build
```

Проверка статуса и логов:
```bash
docker compose ps
docker compose logs -f utility-meter-app
```

## 🧪 Тестирование

Запуск всех автотестов внутри контейнера (используется изолированная временная SQLite БД с production PRAGMA):
```bash
docker compose exec -T utility-meter-app pytest -v
```

Проверка синтаксиса Python:
```bash
docker compose exec -T utility-meter-app python -m compileall -q database services webapp bot_handlers.py main.py config.py tests
```
